FlowRun 개인정보 처리방침

최종 수정일: 2026년 11월 12일 · 적용 버전: v4.0.2 이상 (1-1 은 v4.1.0 기준)

FlowRun(이하 "본 확장")은 Google Flow(flow.google.com)에서의 AI 이미지·영상 배치 생성 자동화를 제공하는 Chrome 확장 프로그램입니다. 본 방침은 본 확장이 처리하는 정보의 종류, 목적, 저장 위치, 사용자 권리를 설명합니다.

1-3. 원격 설정

Flow 화면 글자·모델 이름이 바뀌었을 때 확장 업데이트 없이 맞추기 위해, 본 확장은 운영자 서버에서 설정 파일(글자·숫자만)을 받아 옵니다. 이 요청에는 개인정보나 사용 내용이 담기지 않습니다.

수집하지 않는 정보: 비밀번호, 결제 정보, 위치, 웹 방문 기록, 키 입력 로그, 마우스 위치, 다른 사이트의 콘텐츠, Google Flow 외부의 어떤 데이터도 수집하지 않습니다.

2. 처리 목적

  • 사용자 인증 및 승인 관리: 본 확장은 관리자 승인 기반 베타 서비스입니다. Google 계정으로 로그인한 사용자의 승인 상태(승인/대기)를 확인해 기능 접근을 제어합니다.
  • 중복 가입 방지 및 사용자 식별: uid를 키로 하나의 Google 계정당 하나의 사용자 레코드만 생성합니다.
  • 본 확장 운영자에게 사용자 식별 표시: 관리자가 승인 요청을 검토할 때 본인 확인용으로 email/displayName 노출.
  • 오류 진단 및 안정성 개선(익명 통계에 한함): 1-1의 익명 통계를 집계해 어떤 버전·환경에서 실패가 잦은지 파악하고 수정합니다. 개인별 사용 내역을 들여다보는 용도가 아닙니다.
  • 피드백 확인·답변: 1-2의 피드백을 읽고 문제를 고치거나 답변하는 데만 씁니다.

사용하지 않는 목적: 광고, 마케팅, 외부 판매, 신용도 판단, 머신러닝 학습 데이터, 개인별 프로파일링·행동 추적.

3. 저장 위치 및 제3자

  • Firebase Firestore (Google Cloud) — 프로젝트 ID: flowrun-kr. 계정·승인 정보가 저장됩니다. Google이 관리하는 인프라이며, Google의 개인정보 처리방침이 함께 적용됩니다.
  • Cloudflare Workers / D1 / R2 — 1-1의 익명 통계(D1)와 1-2의 피드백(R2 비공개 저장소)이 저장되고, 1-3의 원격 설정을 내려줍니다. 계정·승인 정보는 저장하지 않습니다. 운영자가 직접 운영하며, 통신 처리 과정에서 Cloudflare가 접속 IP를 인프라 차원에서 처리할 수 있습니다. 본 확장은 IP를 별도로 저장하지 않습니다.
  • Discord — 운영자 알림 채널. 1-2 피드백의 제목·내용·가려진 이메일·버전, 1-1 통계의 집계 요약만 전달됩니다.
  • chrome.storage.local — 설정·적어 둔 프롬프트·작업 기록·로그인 토큰을 사용자 본인 브라우저 내부에 저장. 사용자가 피드백에 작업 기록을 함께 보내기로 고른 경우를 빼고는 외부로 보내지 않습니다.
  • 제3자 제공 없음: 위 인프라 제공자(Google, Cloudflare, Discord) 외 어떠한 제3자에게도 사용자 데이터를 판매·전송·공유하지 않습니다.

4. 보존 및 삭제

  • 보존 기간: 사용자가 삭제 요청을 하기 전까지 또는 본 확장이 종료될 때까지 Firestore에 보관됩니다.
  • 로그아웃 시: chrome.storage.local의 토큰·캐시 정보는 즉시 삭제되지만, Firestore 사용자 레코드는 별도 삭제 요청 전까지 유지됩니다.
  • 확장 제거 시: chrome.storage.local 데이터는 Chrome에 의해 자동 삭제됩니다. Firestore 레코드는 자동 삭제되지 않으므로 제거를 원하시면 아래 연락처로 요청해 주세요.
  • 피드백: 문제 해결·답변을 위해 보관하며, 삭제를 요청하시면 본인이 보낸 피드백 파일을 지웁니다.

5. 사용자의 권리

본 확장 사용자는 언제든 다음을 요청할 수 있습니다:

  • 본인의 Firestore 레코드 열람 (저장된 email, displayName 등 확인)
  • 본인의 Firestore 레코드 삭제 (계정 정보 영구 삭제)
  • 본인이 보낸 피드백 삭제
  • 처리 정지 요청 (서비스 이용 중단)

요청은 아래 GitHub Issues 또는 이메일을 통해 접수합니다. 신원 확인 후 7영업일 이내에 처리합니다.

2. Purposes

  • User authentication and approval management: FlowRun is an admin-approved beta service. We check the approval status (pending/approved) of users signed in with their Google account to gate feature access.
  • Duplicate-account prevention and identification: The UID acts as a primary key — one Google account = one user record.
  • Identification for the extension operator: Email/displayName are shown to the admin during approval review only.
  • Error diagnosis and stability (anonymous statistics only): Aggregating the statistics in 1-1 to see which versions/environments fail most, and fixing them. Not used to inspect any individual's activity.
  • Reading and answering feedback: Feedback in 1-2 is used only to fix problems and reply.

NOT used for: advertising, marketing, third-party sale, credit scoring, ML training, or individual profiling and behavioral tracking.

3. Storage and Third Parties

  • Firebase Firestore (Google Cloud) — project ID flowrun-kr. Stores account and approval data. Managed infrastructure by Google; Google's privacy policy also applies.
  • Cloudflare Workers / D1 / R2 — stores the anonymous statistics in 1-1 (D1) and the feedback in 1-2 (private R2 storage), and serves the remote configuration in 1-3. No account/approval data. Operated by us; Cloudflare may process the connecting IP address at the infrastructure level during transport. FlowRun does not store IP addresses.
  • Discord — the operator's notification channel. Receives only the feedback title, message, masked email and version from 1-2, and aggregate summaries of the statistics in 1-1.
  • chrome.storage.local — settings, saved prompts, activity history and sign-in tokens are kept inside your own browser and are not transmitted, except the activity log you choose to attach to feedback.
  • No third-party sharing: FlowRun does not sell, share, or transfer user data to any party other than the infrastructure providers above (Google, Cloudflare, Discord).

4. Retention and Deletion

  • Retention period: Records remain in Firestore until you request deletion or the extension is discontinued.
  • On sign-out: chrome.storage.local tokens/cache are immediately cleared; Firestore record persists until separate deletion request.
  • On extension uninstall: chrome.storage.local is auto-deleted by Chrome. Firestore record is NOT auto-deleted; contact us to delete it.
  • Feedback: kept to resolve issues and reply; on request we delete the feedback files you sent.

5. Your Rights

You may request at any time:

  • Access to your Firestore record (view stored email, displayName, etc.)
  • Deletion of your Firestore record (permanent removal)
  • Deletion of feedback you sent
  • Suspension of processing (stop using the service)

Submit requests via the contact methods below. We respond within 7 business days after identity verification.

6. Permissions Used

See the Korean section above (Section 6) for the full list: identity, storage, tabs, scripting, downloads, notifications, sidePanel, debugger, and host access to https://flow.google.com/* only. Each permission is used solely for the stated purpose. Because Flow ignores script-generated clicks, debugger attaches only to the Flow tab while a run you started is in progress, sends real mouse/keyboard input (and puts the reference images you chose into Flow's file picker), and detaches when the run ends or you stop it.
